# FastAPI Trip API

A high-performance FastAPI microservice designed for integrating with a shared Laravel database for package management.

## 📄 Documentation
For a complete rundown of the project, including its architecture, tech stack, and API endpoints, please refer to:
- [Project Rundown](docs/project_rundown.md)

## 🚀 Quick Start
```bash
# Sync dependencies
uv sync

# Start the dev server
uv run fastapi dev app/main.py
```
